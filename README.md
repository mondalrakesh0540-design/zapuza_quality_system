# AUTOVERSE 3D Workspace

This workspace houses **AUTOVERSE 3D**, the next-generation 3D automotive explorer web application.

## Quick Start

You can run commands directly from this root directory:

```bash
# Run automated tests
npm test

# Run development server
npm run dev

# Build for production
npm run build
```

The application source code, 3D WebGL components, and data services reside in the [`autoverse/`](./autoverse) directory.
For complete architectural details and documentation, please see [`autoverse/README.md`](./autoverse/README.md).
